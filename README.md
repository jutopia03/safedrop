# SafeDrop

**보내기 직전에 한 번 더 확인하는 사내 파일 전송 채널** — 코디세이 Final-Project · 팀 codev

파일을 보내기 직전, 파일 속 개인정보·민감정보를 찾고 **수신자마다 허용·마스킹·차단**을 판단합니다. 판단 근거는 사내 규정 조항으로 설명하고, 허가된 파일만 서버가 서명한 토큰과 함께 브라우저 간(P2P) 전송합니다.

- **서비스 주소:** https://safedrop-7sx9.onrender.com/ (무료 서버라 첫 접속에 약 1분 걸릴 수 있음)
- **로그인:** 가상 직원을 고르고 시연 비밀번호 입력 (비밀번호는 제출 양식에 별도 기재)
- **시연 영상·화면:** `docs/demo/` (제출 전 추가)

## 왜 필요한가
- 국내 개인정보 유출 신고 중 **업무 과실이 25~30%**(2024년 91건, 2025년 110건). 단체방 게시, 이메일 동보 발송, 잘못 첨부처럼 **"이 파일을 이 사람에게 보내도 되는가"를 묻지 않아 생긴 유출**입니다 (개인정보보호위원회·KISA).
- 같은 파일도 **받는 사람에 따라** 허용 범위가 다르고(인사팀은 원본, 다른 부서는 가린 사본, 협력사는 금지), 번호가 아닌 **문장 속 민감정보**("○○ 과장 공황장애 진단")는 번호 형식으로는 잡히지 않습니다.
- 탐지는 상용 DLP에서 검증된 방식(번호 형식 + 주변 문맥)을 직접 구현했고, SafeDrop이 새로 설계한 것은 **찾은 다음** — 받는 사람마다 다른 처리, 규정 근거와 고칠 위치 안내, 서명 검증 전송, 외부 AI 없는 사내 동작입니다 ([비교](docs/requirements.md))
- 근거와 출처: [요구사항 명세 1장](docs/requirements.md)

## 무엇을 하나
```
업로드 ─▶ 텍스트 추출 (스캔 PDF·사진은 OCR) ─▶ ① 정규식+문맥 탐지 (주민·카드·계좌·연락처…)
                                          └▶ ② AI 문맥 판단 (건강·신념·정치·노조·사생활 문장)
        ─▶ ③ 수신자별 판정 (규칙표: 정보 유형 × 수신자 유형 → 조치 + 조항)
        ─▶ ④ 근거 조항 검색(RAG) + AI 설명 → 인용 검증 통과분만 표시
        ─▶ ⑤ 서명된 전송 허가 토큰 → P2P 전송 (실패 시 10분 메모리 중계) → 수신 브라우저가 서명·해시·수신자·만료 검증
```
- **판정은 규칙이, AI는 판단·설명만**: 허용·마스킹·차단은 규칙표가 결정해 같은 입력엔 같은 결과가 나오고 감사할 수 있습니다. AI 출력은 코드로 검증하고, 실패·의심 시 차단 쪽으로 처리합니다(fail-closed).
- **필수 기술 요소**: 자동화 Workflow(위 ①~⑤) + RAG(사내 규정 조항 검색 기반 설명). 자율 Agent 구조는 의도적으로 쓰지 않았습니다 — 보안 판정은 재현·감사 가능해야 하기 때문입니다.
- 자세히: [아키텍처](docs/architecture.md)

## 직접 실행
```bash
pip install -r requirements.txt
pip install -r requirements-dev.txt && pytest -q      # 자동 테스트 63개 (AI·네트워크 없이 약 10초)
cp .env.example .env                                    # AI 키·시연 비밀번호 설정 (비우면 규칙 탐지만 동작)
uvicorn backend.app.main:app --reload                   # http://localhost:8000
```
- OCR(스캔 PDF·사진)은 Tesseract와 한국어 데이터가 필요합니다(`Dockerfile` 참고). 없으면 스캔 문서는 '확인 불가 → 차단'으로 처리됩니다.
- 폐쇄망(사내 설치): [`deploy/onprem/`](deploy/onprem/README.md) — 앱 + 로컬 LLM(Ollama) 설치 묶음, GPU 16GB 1대 기준. 외부 API 없이 동작
- 실제 도입을 가정한 점검과 로드맵: [아키텍처 6장](docs/architecture.md)

- 업로드 10MB, 로그인 실패 IP당 1분 5회 제한
</details>

## 폴더 구조
```
backend/app/   FastAPI 서버 — extract·ocr(추출), detect(정규식), sensitive(AI 판단), policy(판정), mask,
               retrieve·explain(RAG 설명), permit(서명 토큰), transfer(신호·중계·감사), auth, main
web/           화면 (HTML/JS, WebRTC·WebCrypto)
data/company/  가상 기업 '코데브솔루션(주)': 조직도, 정보보호 규정, 판정 규칙표
data/testset/  팀원이 만든 테스트 문서·정답·민감정보 문장 세트
scripts/       측정 스크립트 (탐지, 검색, AI 판단, AI 설명, 로컬 LLM)
tests/         자동 테스트
docs/          설계·개발 과정·측정 기록·사용자 테스트
```

모든 조직·규정·개인정보는 시연용 가짜 데이터입니다.
