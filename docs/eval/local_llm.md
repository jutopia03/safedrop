# 외부 API vs 로컬 LLM(Ollama) 비교

측정: 팀원 RTX 4080 SUPER(16GB) PC, `scripts/bench_local.py` (원본 결과: `docs/bench/ollama_*.md`, 원본 응답: `raw_*.jsonl`)
판단 문장 세트: 육민호 20문장 / 설명: 정보 유형 5 × 수신자 유형 4 = 20개 상황. 측정 시점 코드: 후보 기준 변경(S12)·설명 보강 전.

| 모델 | 실행 위치 | 민감정보 판단 정확도 (재현율·정밀도) | 판단 시간 | AI 설명 검증 통과 | 설명 시간 | GPU 메모리 |
|---|---|---|---|---|---|---|
| gpt-5-mini | 코디세이 API | 90% (92%·92%) | 121.9초 | (20/20, 이전 측정) | - | - |
| gpt-5.4-mini | 코디세이 API | - | - | 20/20 | 16.3초 | - |
| **qwen3:8b** | 로컬 GPU | **90% (92%·92%)** | 65.2초 | 10/20 | 47.8초 | 5.8GB |
| **exaone3.5:7.8b** | 로컬 GPU | 80% (75%·90%) | 16.1초 | **20/20** | **20.8초** | 5.2GB |
| qwen3:14b | 로컬 GPU | 80% (75%·90%) | 123.6초 | 11/20 | 100.8초 | 9.5GB |

## 해석
1. **역할별로 잘하는 모델이 다르다**: 판단은 qwen3:8b가 외부 API(gpt-5-mini)와 같은 결과(오류 문장까지 동일), 설명은 exaone3.5(LG, 한국어 특화)가 외부 API와 같은 20/20. 외부 API에서 판단·설명 모델을 나눈 것(S8)과 같은 구조가 로컬에서도 성립한다.
2. **큰 모델이 더 좋지 않았다**: qwen3:14b는 8b보다 판단이 낮고 2배 느리다. 정치 성향 문장(s07, s19)을 놓침.
3. **온프레미스 인프라 답변(퍼실리테이터 질문 1-3)**: 판단 qwen3:8b(5.8GB) + 설명 exaone3.5:7.8b(5.2GB)를 함께 올려도 약 11GB → **16GB 소비자용 GPU 1대**로 외부 API와 같은 수준의 판단·설명이 가능하다. 모두 100% GPU에 적재됨(`ollama ps`).
4. **로컬 모델 설명 실패 원인(원본 응답 분석)**: ① 프롬프트 JSON 예시 값을 그대로 베낌(`"rid":"u01"`, 인용문 "조항 원문 일부") ② 5명 중 일부만 답함 ③ 마지막 괄호 누락. 모델 문제가 아니라 견고성 문제로 보고 코드로 대응: 예시를 형식 안내(`<…>`)로 바꿈, 빠진 수신자만 1회 재질문, 닫는 괄호 보정. → 재측정 예정.
