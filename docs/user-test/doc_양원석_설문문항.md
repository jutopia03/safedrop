# SafeDrop 사용자 테스트 설문 문항 (Google Form 입력용)

> Google Form에는 아래 텍스트를 복사해 입력한다. 설문 링크는 PR 본문 또는 `시나리오.md`에 기재한다.
> **설정 권장:** 이메일 수집 끄기, 로그인 요구 끄기, 응답 1회 제한 끄기(익명·간편 응답), 필수 응답은 1~5번.

## 설문 제목
SafeDrop 사용자 테스트 설문

## 설명문
테스트에 참여해 주셔서 감사합니다. 응답은 서비스 개선 목적으로만 사용되며, 개인을 식별하는 정보는 수집하지 않습니다. (소요 시간 약 2분)

---

## 5점 척도 문항 (1=전혀 그렇지 않다 ~ 5=매우 그렇다)

| 번호 | 문항 |
|---|---|
| 1 | 서비스의 판단(허용·마스킹·차단)이 납득되었다. |
| 2 | 판단 근거(규정 조항 등)에 대한 설명을 이해하기 쉬웠다. |
| 3 | 파일을 보내는 과정이 사용하기 쉬웠다. |
| 4 | 마스킹된 사본만으로도 업무를 진행할 수 있을 것 같다. |
| 5 | 실제 업무에서도 이 서비스를 사용하고 싶다. |

Google Form 설정: 객관식 그리드가 아닌 **'선형 배율'** 유형, 1~5, 양 끝 라벨 "전혀 그렇지 않다" / "매우 그렇다".

## 주관식 문항

| 번호 | 문항 | 필수 |
|---|---|---|
| 6 | 사용하면서 불편했거나 이해하기 어려웠던 점이 있다면 적어 주세요. | 선택 |
| 7 | 서비스가 더 나아지려면 어떤 점을 개선하면 좋을지 제안해 주세요. | 선택 |
