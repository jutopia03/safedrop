## 1. 참가자 안내

안녕하세요. 이번 테스트에 참여해 주셔서 감사합니다.

여러분은 **코데브솔루션(주) 영업팀 직원 '변시우'**입니다. 사내 파일 전송 서비스 **SafeDrop**으로 업무 파일을 보내는 상황을 가정하여, 아래 세 가지 과제를 순서대로 수행해 주시기 바랍니다.

- 소요 시간은 약 10분이며 정답은 없습니다. 서비스가 부족한지를 평가하는 테스트이므로 막히는 부분이 있어도 괜찮습니다.
- 아래 샘플 파일은 모두 가짜 데이터입니다. **이 파일만 사용해 주시고**, 본인의 파일이나 실제 개인정보는 업로드하지 말아 주십시오.
- 서버가 무료 서버라 **첫 접속에 약 1분 정도 걸릴 수 있습니다.** 화면이 뜰 때까지 기다려 주십시오.
- 느낀 점은 마지막 설문에 자유롭게 적어 주시기 바랍니다.

3. 비밀번호는 개인 메시지로 안내드린 시연 비밀번호를 입력합니다.

## 2. 과제

### 과제 1. 한 번에 여러 사람에게 보내기

**상황**
신규 입사자 은채린 님(영업팀)의 인사기록카드를 여러 사람에게 공유해야 합니다. 인사팀 마도현, 같은 팀 길하람, 개발팀 탁운재, 협력사 봉태경 네 분입니다.

**해야 할 일**
1. 변시우로 로그인합니다.
2. `sample1_인사기록카드.docx`를 선택합니다.
3. 수신자 **네 명을 모두 체크**합니다.
4. **검사하기**를 누릅니다.
5. **수신자별로 나온 결과와 설명**을 차분히 읽어 봅니다. (이 과제에서는 전송하지 않고 결과 확인까지만 합니다.)

**참고:** 결과가 수신자마다 같은지 다른지, 왜 그런지에 주목해 주세요.

---

### 과제 2. 가려진 사본 확인하고 보내기

**상황**
개발팀 탁운재 님이 신규 입사자 은채린 님에게 연락할 일이 있다며 같은 인사기록카드를 요청했습니다.

**해야 할 일**
1. 다시 `sample1_인사기록카드.docx`를 선택하고 수신자를 **탁운재(개발팀) 한 명**만 체크합니다.
2. **검사하기**를 누릅니다.
3. 서비스가 안내하는 **가려진 사본(마스킹본)**을 확인합니다. 어떤 항목이 가려졌는지, 가려진 사본으로 업무가 가능할지 살펴봅니다.
4. **허가된 대상에게 전송**을 눌러 전송을 마칩니다.

---

### 과제 3. 차단 사유 읽기

**상황**
영업팀 주간회의록을 개발팀 탁운재 님에게도 공유하려 합니다.

**해야 할 일**
1. `sample2_주간회의록.docx`를 선택하고 수신자를 **탁운재(개발팀) 한 명**만 체크합니다.
2. **검사하기**를 누릅니다.
3. 화면에 나온 **결과와 사유, 근거 조항**을 읽습니다.
4. 읽은 내용을 바탕으로, 이 상황에서 **본인이라면 다음에 어떻게 할지** 생각해 봅니다. (예: 파일 수정, 담당자에게 문의, 다른 방법 모색)

**참고:** 예상과 다른 결과가 나와도 괜찮습니다. 화면에 나온 그대로 진행하시고, 다르다고 느낀 점은 설문 주관식에 적어 주세요.
