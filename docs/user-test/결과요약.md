## 3. 해석과 한계
- **핵심 동작은 처음 보는 사람도 이해했다:** 이해도 확인 5/5, '판단 납득' 4.8. 수신자별 판정이 별도 설명 없이 화면만으로 전달됨.
- **가장 낮은 항목은 '근거 설명'과 '사용 의향'(4.6):** 근거 설명 점수를 낮게 준 2명이 F1(어디가 걸렸는지)을 말한 사람과 겹친다 — 설명 문장보다 **문서 속 위치**를 원했다는 뜻으로 해석하고 F1으로 대응했다.
- **한계:** 5명의 작은 표본이고, 지인 중심 모집이라 점수가 후하게 나왔을 수 있다(천장 효과). 비대면이라 막힌 지점·소요 시간은 관찰하지 못했다. 반영 후 버전은 아직 사용자 테스트를 다시 받지 않았다.

원본 응답(스프레드시트)은 개인 정보 보호를 위해 올리지 않고 이 요약만 남긴다.
