## 1. 5점 척도 (1=전혀 그렇지 않다 ~ 5=매우 그렇다)

Google Form 유형은 **'선형 배율'**, 1~5로 하고 **양 끝 라벨을 반드시 입력**한다: 1 = "전혀 그렇지 않다" / 5 = "매우 그렇다"

| 번호 | 문항 |
|---|---|
| 1 | 서비스의 판단(허용·마스킹·차단)이 납득되었다. |
| 2 | 판단 근거(규정 조항 등)에 대한 설명을 이해하기 쉬웠다. |
| 3 | 파일을 보내는 과정이 사용하기 쉬웠다. |
| 4 | 마스킹된 사본만으로도 업무를 진행할 수 있을 것 같다. |
| 5 | 실제 업무에서도 이 서비스를 사용하고 싶다. |

## 2. 주관식 (선택 응답)

| 번호 | 문항 |
|---|---|
| 6 | 사용하면서 불편했거나 이해하기 어려웠던 점이 있다면 적어 주세요. 예상과 다른 결과가 나왔다면 그 내용도 적어 주세요. |
| 7 | 서비스가 더 나아지려면 어떤 점을 개선하면 좋을지 제안해 주세요. |

## 3. 이해도 확인 (객관식, 필수)

비대면 테스트라 과제 수행 여부와 결과 이해 여부를 직접 볼 수 없어서 넣는 문항이다. 정답은 폼에 표시하지 않는다.

| 번호 | 문항 | 보기 | 정답 (운영자용) |
|---|---|---|---|
| 8 | 과제 1에서 협력사(봉태경)에게는 어떤 결과가 나왔습니까? | 원본 그대로 전송 가능 / 마스킹본(일부 가림) / 전송 차단 / 기억나지 않음 | 전송 차단 |
