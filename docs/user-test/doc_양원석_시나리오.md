## 4. 과제

### 과제 1. 같은 파일을 두 곳에 보내기

**상황**
인사팀에서 신규 입사자 서류 확인을 위해 인사기록 파일을 요청했습니다. 같은 시간에 협력사 담당자도 해당 파일을 요청했습니다. 

**해야 할 일**
1. 제공된 `인사기록` 파일을 선택합니다. `[파일명 확정 후 수정]`
2. 수신자를 **인사팀 담당자(사내)**로 지정하여 전송을 시도합니다.
3. 같은 파일을 수신자 **협력사 담당자(외부)**로 바꾸어 다시 전송을 시도합니다.
4. 두 경우에 서비스가 내린 판단이 각각 무엇이었는지 확인합니다.

**참가자에게 묻는 질문 (구두 또는 화면 확인용 체크)**
- 두 경우의 결과가 같았습니까, 달랐습니까?
- 서비스의 판단에 동의하십니까?

**완료 기준:** 두 수신자에 대한 판단 결과를 각각 확인했다.

---

### 과제 2. 마스킹된 사본 확인하기

**상황**
협력사 담당자에게는 개인정보를 가린 사본만 보낼 수 있다고 합니다. 

**해야 할 일**
1. 과제 1의 파일을 협력사 담당자에게 보내는 상황에서 서비스가 안내하는 **마스킹본(가려진 사본)**을 확인합니다. `[마스킹 화면 확인 후 수정]`
2. 어떤 항목이 가려졌는지, 가려진 사본으로 업무가 가능할지 살펴봅니다.
3. 마스킹본 전송을 완료합니다.

**참가자에게 묻는 질문**
- 가려진 부분이 적절했습니까? (너무 많이 / 적절 / 너무 적게)
- 이 사본만으로 협력사와 업무를 진행할 수 있겠습니까?

**완료 기준:** 마스킹본을 확인하고 전송을 완료했다.

---

### 과제 3. 차단 사유 읽기

**상황**
다음 파일을 협력사 담당자에게 보내려 하는데, 서비스가 전송을 막았다고 합니다. 

**해야 할 일**
1. 차단 대상 문서 `[문서 확정 후 지정]`를 선택하고 협력사 담당자를 수신자로 지정해 전송을 시도합니다.
2. 서비스가 보여 주는 **차단 사유와 근거 조항**을 읽습니다. `[차단 화면 확인 후 수정]`
3. 읽은 내용을 바탕으로, 이 상황에서 본인이 다음에 어떻게 할지 직접 말하거나 적어 봅니다. (예: 파일 수정, 담당자에게 문의, 다른 방법 모색)

**참가자에게 묻는 질문**
- 왜 차단되었는지 이해했습니까?
- 설명을 읽고 다음에 무엇을 해야 하는지 알 수 있었습니까?

**완료 기준:** 차단 사유를 확인하고, 다음 행동을 스스로 설명할 수 있다.

## 5. 운영자 관찰 포인트

참가자에게는 공개하지 않는다. 응답과 함께 정리해 개선점으로 연결한다.

| 과제 | 관찰 포인트 | 예상 결과 `[정책 담당 확인 필요]` |
|---|---|---|
| 1 | 수신자에 따라 판단이 달라지는 것을 인지했는가 | 사내: 허용 또는 마스킹 / 외부: 마스킹 또는 차단 |
| 1 | 오탐·미탐 여부 (판단이 실제 내용과 맞는가) | 주민번호 탐지 정확 |
| 2 | 마스킹 범위가 업무에 적절한가, 사본임을 인지했는가 | 주민번호 뒷자리 등 탐지 항목만 가려짐 |
| 3 | 근거 조항 문구를 이해했는가, 다음 행동을 알았는가 | 근거 조항 번호와 사유 표시 |
| 전체 | 막힌 지점, 소요 시간, 오조작, 질문 내용 | - |

**유의사항**
- 참가자가 질문하면 정답을 알려주지 않고 "화면에서 보이는 대로 진행해 주세요"라고 안내한다.
- 서비스가 느리거나 오류가 나면(무료 호스팅 첫 접속 지연 가능) 그 사실을 기록하고, 참가자에게 잠시 후 재시도를 안내한다.
