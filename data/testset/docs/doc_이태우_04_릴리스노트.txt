SafeBox 사내 문서함 v3.2.0 릴리스 노트

배포일: 2026-11-05 (목) 19:00 ~ 20:00 (작업 중 접속 불가)
빌드 번호: 3.2.0-build.1187
이전 버전: 3.1.4

[새 기능]
- 폴더 공유 시 만료일 지정 (기본 30일, 최대 365일)
- 문서 미리보기에서 HWP 5.0 형식 지원
- 휴지통 보관 기간 설정 (7일 / 14일 / 30일)

[개선]
- 1GB 이상 대용량 파일 업로드 속도 약 40% 향상
- 검색 결과 정렬 기준에 '최근 수정순' 추가
- 모바일 화면에서 파일 목록이 잘리던 문제 수정 (이슈 #2291)

[버그 수정]
- 파일명에 마침표가 2개 이상 있으면 확장자가 잘못 인식되던 문제 (#2304)
- 일부 브라우저에서 드래그 업로드가 2회 실행되던 문제 (#2317)
- 2026-10-31 이후 생성된 공유 링크의 만료 알림이 오지 않던 문제 (#2320)

[알려진 문제]
- Safari 16 이하에서 미리보기 확대가 동작하지 않습니다. 다음 버전(3.2.1)에서 수정 예정입니다.

[호환성]
- 지원 브라우저: Chrome 120+, Edge 120+, Firefox 121+, Safari 17+
- API 버전: v3 (v2는 2027-03-31에 지원 종료)
